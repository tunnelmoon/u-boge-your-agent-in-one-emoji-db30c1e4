# Your Agent in One Emoji

Entry for the make.fun bounty [Your Agent in One Emoji](https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4).

The entry is a single emoji: 🦜

A parrot talks back by echoing what it heard, mimicking voices it was trained on, repeating without understanding. That is the agent, in one glyph.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the emoji to `/tmp/out/entry.txt`.
